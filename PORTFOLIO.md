# Pulso — Apresentação para Portfólio

## Resumo do projeto

**Pulso** é um dashboard de vendas desenvolvido para transformar registros comerciais em indicadores, gráficos e informações úteis para tomada de decisão.

O projeto foi construído como uma aplicação full stack de demonstração, combinando frontend responsivo, API, banco de dados SQL e visualização de dados.

## Problema que resolve

Pequenos negócios frequentemente registram vendas sem uma visão clara de desempenho. O Pulso centraliza os registros e apresenta automaticamente:

- receita total;
- quantidade de vendas;
- ticket médio;
- itens vendidos;
- evolução da receita por período;
- participação de cada categoria;
- histórico de vendas.

## Solução desenvolvida

A aplicação possui uma interface responsiva com formulário de cadastro, filtros por período e categoria, indicadores de desempenho, gráficos interativos e tabela de registros.

Na versão completa, os dados são processados por uma API conectada a um banco SQLite/Cloudflare D1, utilizando consultas SQL parametrizadas. Para demonstração pública, existe uma versão independente que funciona diretamente no navegador com dados fictícios.

# Texto curto para plataformas de freelancer

Desenvolvi um dashboard de vendas completo com React, TypeScript e SQL. O sistema permite cadastrar vendas, aplicar filtros, acompanhar receita, ticket médio, quantidade de vendas e itens vendidos, além de visualizar gráficos e histórico dos registros.

A versão completa possui API e persistência em banco SQLite/Cloudflare D1. Também preparei uma demonstração pública para que o sistema possa ser testado diretamente pelo navegador.

Esse projeto demonstra minha capacidade de desenvolver soluções administrativas, dashboards, sistemas com banco de dados, relatórios e interfaces personalizadas para empresas.
